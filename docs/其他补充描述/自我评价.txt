在读软件工程本科（2027 届）。上大学后我没把自己关在课堂里，很早就进了校 ACM 算法集训队（大一上以校内第 19 名入选），之后进了「华为—昇腾」创享社嵌入式方向，大一下进了广工广东省物理信息融合实验室国家地方工程中心，跟着黄国恒副教授做项目。这三步给我两样东西：还算扎实的算法底子，和“代码最终要落在设备和现场上”的意识。

真正让我长本事的是这几段校企合作项目，走的是一条从参与到负责再到主导的线。

最早是南方电网广州电力工程监理的办公自动化 RPA（10 万，技术负责人，已验收交付）。这段做的是“把业务规则变成程序”：把甲方报表里筛选、分列、多条件嵌套统计的口径抽象为可复用 Pandas 函数库；更关键的是把报表结构从代码里剥出来，改成结构化 JSON 加配置映射注入 Excel——模板再变，只改配置、不动代码。交付时打成免安装程序，甲方没装 Python 的 Windows 内网机上直接能跑。原本每天 1.5 小时的手工统计，最后压到 3 分钟以内。

后来是广东交科检测的钢筋直径与间距检测设备（25 万，技术负责人）。这次要解决“在设备上跑得稳”：推理、采集、渲染和串口在单板上互抢资源，我把 AI 推理和系统调度物理隔成两个节点——Jetson Nano 专跑 UNet 分割、OrangePi 负责采集、激光解析和界面；代价是多一层通信，换回来的是资源不抢、故障域隔离、推理节点可独立换型。还打通 4 路激光串口链路、做像素到实际尺寸的换算，并把帧同步、心跳降级和参数配置化收成「协议冻结—状态机—自动降级」的闭环，让设备在无人值守时也能自证状态、安全退化。

再往后是机场物流集团智慧物流系统二期（55 万，校企联合框架累计 90 万）。这次我是项目总负责人，独立统筹业务调研、合同拟定、架构设计到验收交付，并主导库区 11 类违规行为的算法开发。最硬的是国产边缘算力适配——把模型转到北京灵汐 HS100-L 类脑芯片上，用 LynSDK 重写推理管线，单路视频延迟压进 200ms。系统侧也从 Spring Boot 分层按业务 SOP 重组成纵向分层，最后收敛成以通信中枢为中心的星形拓扑，组件不再两两直连；部署上做 Docker 容器化，配云边监控的 15 条以上告警，P1 故障恢复控制在 5 分钟内、可用性 99.5%，并按 100TB 视频归档与亿级事件检索的设计要求规划存储与检索。

中间还夹着两段实习，把 AI 工程化的面铺宽了。在广州光点信息科技，我负责反爬采集链路、本地 faster-whisper 与 SenseVoice 双 STT 引擎的部署与路由，并把大模型能力从主业务流剥离成 FastAPI 微服务；在广东省国土资源测绘院，我用「逻辑核心 + 功能插件」微内核加六层分层，配意图路由和三级权限，在数据“绝对不出域”的前提下把一套本地化 RAG 问答系统从 0 做到 1，专业问答忠实度 95% 以上、相关率 90% 以上。

项目做得多了，我在意的不是“把功能写出来”，而是“怎么把事情设计对”。

一层是工程架构设计。机场和交科这两个项目里，我最在意的往往不是某个功能有没有实现，而是几处架构取舍：报表结构要不要从代码里剥离、推理和调度要不要分两个节点、检索链路要不要做成可插拔微内核、组件之间要不要收敛到一个中枢。这些没有标准答案，但每选一次，系统后面的可维护性和生命周期就跟着变。

另一层是系统工程。事做久了会发现，项目真正难的地方很少在单个模块，而在几方能否对齐：硬件装得上、集群稳得住、模型跑得动、数据既要出不去又要查得到，还得经得起长期运维——这些是同一件事的不同侧面，得一起设计。

顺着这个习惯，我也把想法往“工程规范”上落：做交科时把项目级 AGENTS.md 放在仓库根当架构约束层，节点文档承接实现细节，形成「约束层 → 实例层」两级；再把这些经验做成机制——任务锚点三层追踪、锚点与 commit hash 双向绑定、提交消息模板和破坏性命令红线。

最后是我一直在做的：面向多 Agent 协作的工程规约体系——一套我自己设计的 Agent / harness 框架。起因很朴素：直接给 Agent 下指令不可靠，产出高度依赖无歧义引导，这跟软件工程里的规范问题几乎一样。于是我把它当正式课题做：划出约束层、知识层、实例层三层逻辑，落地为 AGENTS.md 与 .spec/ 双载体，配 27 项机制，并规划向 harness 演进的路径（L0～L4 五层分离、五类 CLI 契约先行）。这件事没有外部委托，纯粹是我自己想把它想清楚，也是我最愿意长期做深的方向。

另外，技术负责人和总负责人我都做过，习惯在甲方、导师、跨部门之间收敛目标、推动决策——既沉得下去写代码，也站得出来对外沟通。
