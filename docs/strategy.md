# strategy.md — 简历编写与投递策略

> **定位**：简历**实例**（`Resume-{目标}.md`，区别于母版 `Resume.md`）的定制操作流程与实例构建方案的唯一权威文档。
> **分工**：母版维护走 `AGENTS.md` §3.1；实例登记见 [`INDEX.md`](INDEX.md) §2；投递 tag 规范见 [`tag.md`](tag.md)，日志见 [`TargetCompanies.md`](TargetCompanies.md)。

## 定制投递流程（两阶段，且相对独立）

> **实例构建**与**投递快照**是两个相对独立的阶段：构建产出可投的实例版本；投递快照基于任一已构建的 `active` 实例执行——可重复、构建后不投也合法、投递无需重新构建。

### 阶段 A：实例构建（产出一个可投版本）

1. **选取目标**：从 [`TargetCompanies.md`](TargetCompanies.md) 按公司性质分组选取目标公司。
2. **复制模板并命名**：复制 `Resume-Lite.md`，重命名为 `Resume-{目标}-{版本}-base.md`（如 `Resume-金融科技-v1.0-base.md`）——**构建时就确定版本号并命名好**，`-base` 尾缀标识这是实例本体。禁止直接改动模板。
3. **填充内容**：基于母版 `Resume.md` 的内容替换骨架条目，按目标岗位在下方`实例构建方案设计`中匹配对应方案，**依方案裁剪详略**（实例内容偏离母版属定制的意义，结构基准仍源自模板）。
4. **构建 PDF**：`bash _temp/scripts/build-pdf.sh Resume-{目标}-{版本}-base.md _output/Resume-{目标}-{版本}-base.pdf`，输出至 `_output/`。
5. **登记实例**：立即在 [`INDEX.md`](INDEX.md) §2 台账登记（只记 md 源文件，PDF 产物不入账，状态 `active`），提交 `build(resume): 生成 XX 投递版 PDF`。

### 阶段 B：投递快照（基于已有实例的一次投递）

前提：存在任一 `active` 状态的实例（刚构建的，或历史构建的——**无需重新构建**）。

1. **选取实例版本**：从 `INDEX.md` §2 的 `active` 实例中选定本次投递所用的文件；如需内容调整，先回阶段 A 迭代出新版本（新版本 = 新的 `-{版本}-base` 文件）。
2. **生成投递副本**：将所选 `Resume-{目标}-{版本}-base.md` 复制一份，尾缀 `-base` 改为 `-{投递公司名称}-{YYYYMMDD}`，得到 `Resume-{目标}-{版本}-{投递公司名称}-{YYYYMMDD}.md`（如 `Resume-金融科技-v1.0-招银网络-20260910.md`）——**文件名即投递记录**，实际投出的就是这份副本（PDF 按同名构建）。
3. **打投递快照 tag**：`git tag v{版本}-{投递公司名称}-{YYYYMMDD}`——与投递副本文件名的版本 / 公司 / 日期三要素一致；格式与铁律见 [`tag.md`](tag.md)。
4. **记录投递日志**：在 [`TargetCompanies.md`](TargetCompanies.md) 的投递日志追加一行（日期 / 简历文件 / 目标公司），其中「简历文件」填**投递副本文件名**；不覆盖旧记录。
5. **更新状态**：公司清单中该公司的「投递简历 / 状态」列更新为最新进展（`投递中` / `一面` / `二面` / `offer` / `挂`），「投递简历」填投递副本文件名；`INDEX.md` §2 该实例的「对应 tag」列更新为**最新一次**投递的 tag。

## 实例构建方案设计

> **方案库定位**：为不同目标类型提供实例裁剪依据——构建实例（阶段 A 第 3 步）时，按目标公司所属分组匹配对应方案执行。
> 方案按 [`TargetCompanies.md`](TargetCompanies.md) 的公司性质分组组织；项目的取舍依据是 [`INDEX.md`](INDEX.md) §1「相关领域」。

### 方案条目结构约定

每个方案（一个小节）含五个字段：

| 字段 | 含义 |
|---|---|
| 适用分组 | 对应 TargetCompanies 的公司性质分组 |
| 前置项目 | 详写、置于靠前位置的经历（按 INDEX §1 相关领域匹配） |
| 常规保留 | 正常篇幅保留的经历 |
| 弱化简写 | 简写或省略的经历 |
| 技能侧重 | 「相关知识技能」章节的调整方向 |
