## 适用领域分组

普通互联网（大厂）

## 方案构建意图简述

① 大厂最看重"能否把一个完整项目从立项交付到上线"与扎实的算法底子。
② 本方案选「机场物流系统（总负责人，撑全生命周期交付与统筹）+ 光点短视频系统（撑微服务解耦与混合推理调度）+ 测绘院知识库（撑 PB 级数据处理与权限治理）+ 算法竞赛（撑算法硬实力）」四条为骨架。
③ 与同届相比，形成"能独立扛交付 + 有规模化数据处理 + 算法有硬背书"的组合，而非只写过业务代码。

## 关键优势项目

- 关键项目1：
    需要突出的要点有：`90 万合同项目总负责人 + 全生命周期交付——大厂看工程成熟度、责任与协作；分支：业务后端/客户端岗看交付与统筹，基础架构岗看 Docker/监控体系`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统迭代二期 项目总负责人 | 2025.07 - 2026.09

**项目概述**：合同 55 万的库区 AI 监控系统（校企联合框架累计 90 万），本人作为总负责人独立统筹全生命周期。

**核心工作**：
- 从业务调研、合作洽谈、技术合同拟定到立项、架构设计、验收交付均作为核心决策者推进
- 多端协同与场景化分层：按场景设计分层技术架构（感知→时空建模→轨迹决策→响应中枢→系统赋能），落地边缘推理 + 中央归档检索协同
- 系统架构演进：由 Spring Boot 分层经 SOP 纵向业务分层收敛为星形 Hub-Spoke 通信中枢，组件统一经中枢单一契约对接
- 主导多场景 AI 视觉算法攻坚与国产边缘算力部署，保障项目按期高质量交付
- 建立 Docker 容器化部署、云边监控体系（Prometheus+Grafana，15+ 告警）与自动化运维流程，可用性 99.5%

**成果**：按期高质量验收，获甲方高层认可。
```

- 关键项目2：
    需要突出的要点有：`微服务解耦 + 异步任务编排 + 混合推理调度——互联网工程风格的标准化设计；分支：后端/平台岗看服务化与队列设计，AI 应用岗看推理调度`  
    示范内容如下：
```markdown
#### 广州光点信息科技 | Python 开发实习生（AI 研发组） | 2025.03 - 2025.06

**项目概述**：全媒体热点追踪与 AI 自动化短视频生成矩阵系统，从 0 到 1 打通"监控-生成-合成"全链路。

**核心工作**：
- 基于 FastAPI 完成大模型能力的服务化拆分：要点提取、脚本二创各自封装为独立微服务，对外提供标准接口
- 跨系统协作契约：引入 Celery + Redis 异步任务队列解耦下载与推理流程，以标准化 JSON 数据交换协议与下游数字人系统交接脚本/时间轴/素材元数据，把跨部门对接成本固化为一次性接口约定
- 云边混合推理调度与成本/时延/质量三角权衡：常规任务走本地 vLLM（成本与数据可控），复杂创意动态路由云端 API（质量优先），含 API Key 池轮询与指数退避重试
- 基于 UI 自动化实现多平台反爬采集与数据清洗，保障上游数据供给

**成果**：单条热点到视频产出从人工数小时压缩至 15 分钟内。
```

- 关键项目3：
    需要突出的要点有：`PB 级数据 + 分布式流水线 + 千万级向量存储——大规模数据处理能力；分支：数据/存储方向看流水线与向量库，算法方向看检索增强`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10

**项目概述**：GDCORS 智能知识库与政企本地化 RAG 问答系统，支撑 PB 级地理空间业务数据场景。

**核心工作**：
- 主导分布式文档解析流水线：集成 OCR 与版面分析，多源资料经清洗与分块（Chunking）后写入 Milvus 向量库，并以异步任务队列承载海量数据的耗时处理
- 采用「逻辑核心 + 功能插件」微内核架构 + 六层分层（基础硬件→数据采集→逻辑核心→插件支持→服务集成→应用交互），插件标准接口挂载向量库/模型/意图识别
- 数据隔离分流与权限治理：BERT 微调意图二分类路由，内部分支走本地库（数据不出内网）、外部经安全通道受控访问；员工/项目经理/管理员三级权限
- 实现千万级文档块在 Milvus 向量数据库的高效存储与检索
- 设计意图识别路由 + HyDE + 多路召回（向量+BM25）+ BGE-Reranker 重排序

**成果**：专业问答准确率 90%+；数据"不出域"合规架构下内网稳定运行。
```

- 关键项目4：
    需要突出的要点有：`算法赛事背书——大厂笔试/面试的算法能力硬通货；分支：后端/平台岗看算法名次，客户端岗看团队负责人角色与作品开发能力`  
    示范内容如下：
```markdown
- **PTA 天梯团体算法竞赛**：全国高校第五名（校 ACM 集训队核心成员）
- **第 17 届中国大学生计算机设计大赛**：3 项作品入围省赛（担任团队负责人）
```
