普通互联网（大厂）

## 关键优势项目

- 关键项目1：
    需要突出的要点有：`90 万合同项目总负责人 + 全生命周期交付——大厂看工程成熟度、责任与协作；分支：业务后端/客户端岗看交付与统筹，基础架构岗看 Docker/监控体系`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统二期 项目总负责人 | 2025.07 - 2026.09

**项目概述**：合同 55 万的库区 AI 监控系统（校企联合框架累计 90 万），本人作为总负责人独立统筹全生命周期。

**核心工作**：
- 从业务调研、合作洽谈、技术合同拟定到立项、架构设计、验收交付均作为核心决策者推进
- 主导多场景 AI 视觉算法攻坚与国产边缘算力部署，保障项目按期高质量交付
- 建立 Docker 容器化部署、云边监控体系（Prometheus+Grafana，15+ 告警）与自动化运维流程，可用性 99.5%

**成果**：按期高质量验收，获甲方高层认可。
```

- 关键项目2：
    需要突出的要点有：`微服务解耦 + 异步任务编排 + 混合推理调度——互联网工程风格的标准化设计；分支：后端/平台岗看服务化与队列设计，AI 应用岗看推理调度`  
    示范内容如下：
```markdown
#### 广州光点信息科技 | Python 开发实习生（AI 研发组） | 2025.03 - 2025.06

**项目概述**：全媒体热点追踪与 AI 自动化短视频生成矩阵系统，从 0 到 1 打通"监控-生成-合成"全链路。

**核心工作**：
- 基于 FastAPI 完成大模型能力的服务化拆分：要点提取、脚本二创各自封装为独立微服务，对外提供标准接口
- 引入 Celery + Redis 异步任务队列解耦下载与推理流程，并制定标准化 JSON 数据交换协议对接下游数字人系统
- 设计云边混合推理调度：常规任务走本地 vLLM，复杂创意动态路由云端 API，含 API Key 池轮询与指数退避重试
- 基于 UI 自动化实现多平台反爬采集与数据清洗，保障上游数据供给

**成果**：单条热点到视频产出从人工数小时压缩至 15 分钟内。
```

- 关键项目3：
    需要突出的要点有：`3PB 级数据 + 分布式流水线 + 千万级向量存储——大规模数据处理能力；分支：数据/存储方向看流水线与向量库，算法方向看检索增强`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10

**项目概述**：GDCORS 智能知识库与政企本地化 RAG 问答系统，支撑 3PB 级地理空间业务数据场景。

**核心工作**：
- 主导分布式文档解析流水线：集成 OCR 与版面分析，滑动窗口+语义边界分块（Chunking），Celery 异步队列处理海量数据
- 实现千万级文档块在 Milvus 向量数据库的高效存储与检索
- 设计意图识别路由 + HyDE + 多路召回（向量+BM25）+ BGE-Reranker 重排序

**成果**：专业问答准确率 90%+；数据"不出域"合规架构下内网稳定运行。
```
