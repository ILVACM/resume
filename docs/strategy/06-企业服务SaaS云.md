## 关键优势项目

- 关键项目1：
    需要突出的要点有：`JSON 配置化引擎 + GUI 交付 + 企业内网部署——企业软件工程化交付全链路；分支：SaaS/企业软件公司看可维护性设计（配置化），乙方交付公司看甲方内网落地能力`  
    示范内容如下：
```markdown
#### 南方电网广州电力工程监理有限公司 | 办公自动化 RPA 项目 核心研发成员 | 2024.10 - 2025.01

**项目概述**：面向电力监理业务的数据清洗与报表自动化 RPA 系统（已验收交付），将每日 1.5 小时手工统计压缩至 3 分钟。

**核心工作**：
- 创新设计基于 JSON 的"数据-模板"解耦映射引擎：报表模板变更只需改配置无需改代码，大幅提升可维护性
- 攻克异构数据源融合：XLS/XLSX 底层 COM 转换、空白行列剔除、多源数据 Merge 精准合并
- GUI 可视化封装 + PyInstaller 打包，确保甲方无 Python 环境的 Windows 内网终端稳定运行

**成果**：系统成功交付并应用于日常安全督查业务，消除人工统计错漏，获甲方高度评价。
```

- 关键项目2：
    需要突出的要点有：`企业知识库产品化 + 量化评估闭环——企业服务公司看知识管理/检索产品的落地方法论；分支：与 AI 组示范侧重不同，此处强调产品化与交付`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10

**项目概述**：GDCORS 智能知识库——面向测绘院海量非结构化专业文档与 3PB 级业务数据的本地化知识管理产品，满足政企数据"不出域"合规要求。

**核心工作**：
- 主导需求调研与期望管理：以早期 Demo 与量化数据收敛目标，将范围从"开放式通用问答"收敛至"精准检索与故障排查"，规避范围蔓延
- 打通文档解析到向量检索的完整产品链路：千万级文档块入库 Milvus，并交付需求、技术方案、测试、工作总结全套文档
- 从 0 到 1 建立 LLM-as-a-Judge 量化评估闭环（相关性/准确性/幻觉率），以指标驱动产品迭代

**成果**：专业问答准确率 90%+，本地化部署 Qwen2.5-14B 内网稳定运行，交付链完整。
```

- 关键项目3：
    需要突出的要点有：`Docker 容器化 + Prometheus 监控 + 自动化运维——云与运维方向的基础设施能力；分支：云厂商/运维平台岗看监控与高可用设计`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统一/二期 | 项目总负责人(二期)/运维(一期) | 2024.09 - 2026.09

**项目概述**：校企联合框架（累计合同 90 万），一期海关安检智能化、二期转运库区监控，分两期独立立项交付。

**核心工作**：
- 设计 Docker 容器化 B/S 部署方案，LynSMI + Prometheus+Grafana 云边监控（15+ 告警规则），P1 故障恢复 <5 分钟、可用性 99.5%
- 攻克安检机专有协议壁垒，实现高并发视频流稳定推送、提取与硬解码
- Shell 自动化部署脚本与 MySQL 定时备份方案，建立故障诊断流程

**成果**：两期均按期验收交付，系统整体可用性达 99.5%。
```

- 关键项目4：
    需要突出的要点有：`微服务 + 异步队列——SaaS 后端的解耦与吞吐设计；分支：与普通互联网组示范侧重一致，此处看企业级稳定性`  
    示范内容如下：
```markdown
#### 广州光点信息科技 | Python 开发实习生（AI 研发组） | 2025.03 - 2025.06

**项目概述**：全媒体热点追踪与 AI 自动化短视频生成矩阵系统，从 0 到 1 打通"监控-生成-合成"全链路。

**核心工作**：
- 基于 FastAPI 将大模型能力封装为独立微服务（要点提取/脚本二创标准接口）
- 引入 Celery + Redis 异步任务队列，解耦下载与推理流程，制定标准化 JSON 数据交换协议对接下游系统
- 本地 vLLM 部署 Qwen2.5-14B 与 Llama 3，复杂任务动态路由云端 API

**成果**：单条热点到视频产出从人工数小时压缩至 15 分钟内。
```

- **第 17 届中国大学生计算机设计大赛**：3 项作品入围省赛（担任团队负责人）
