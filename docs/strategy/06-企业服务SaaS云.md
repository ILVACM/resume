## 适用领域分组

企业服务 / SaaS / 云

## 方案构建意图简述

① 企业服务 / SaaS / 云方向最看重"软件能否工程化交付、是否好维护可配置"，以及工程治理能力。
② 本方案选「RPA 系统（技术负责人，撑架构升级决策与零代码引擎）+ 测绘院知识库（撑产品化与权限治理）+ 个人工程实践（撑工程规约体系）+ 光点系统（撑微服务与异步队列）」四条为骨架。
③ 与同届相比，形成"能交付可配置企业软件 + 有工程规约体系 + 有云原生服务化经验"的组合，而非只做过脚本工具。

## 关键优势项目

- 关键项目1：
    需要突出的要点有：`JSON 配置化引擎 + GUI 交付 + 企业内网部署——企业软件工程化交付全链路；分支：SaaS/企业软件公司看可维护性设计（配置化），乙方交付公司看甲方内网落地能力`  
    示范内容如下：
```markdown
#### 南方电网广州电力工程监理有限公司 | 办公自动化 RPA 辅助软件开发项目 技术负责人 | 2024.10 - 2025.01

**项目概述**：面向电力监理业务的数据清洗与报表自动化 RPA 系统（已验收交付），将每日 1.5 小时手工统计压缩至 3 分钟。

**核心工作**：
- 架构升级决策：摒弃硬编码写表，将统计结果先输出结构化 JSON，再由 config 坐标映射规则驱动注入目标 Excel；报表结构剥离为配置，模板变更只需改文件无需改代码
- 面向非技术用户的零代码可视化交互引擎：数据勾选/督查反匹配/口径选择全收敛到 GUI 与配置文件，业务人员不接触代码即可自助完成数据导入到报表输出全流程
- 攻克异构数据源融合：XLS/XLSX 底层 COM 转换、空白行列剔除、多源数据 Merge 精准合并
- PyInstaller 打包 + 全局日志捕获的工程化交付链路，确保甲方无 Python 环境的 Windows 内网终端稳定运行

**成果**：系统成功交付并应用于日常安全督查业务，消除人工统计错漏，获甲方高度评价。
```

- 关键项目2：
    需要突出的要点有：`企业知识库产品化 + 量化评估闭环——企业服务公司看知识管理/检索产品的落地方法论；分支：与 AI 组示范侧重不同，此处强调产品化与交付`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10

**项目概述**：GDCORS 智能知识库——面向测绘院海量非结构化专业文档与 PB 级业务数据的本地化知识管理产品，满足政企数据"不出域"合规要求。

**核心工作**：
- 主导需求调研与期望管理：以 Demo 与量化数据收敛目标，将范围从通用问答收敛至"精准检索与故障排查"，规避范围蔓延
- 采用「逻辑核心+功能插件」微内核架构+六层分层，插件标准接口挂载向量库/模型/意图识别
- 数据隔离分流与权限治理：BERT 微调意图二分类路由（内部本地库、外部安全通道受控），三级权限
- 打通文档解析到向量检索链路：千万级文档块入库 Milvus，交付需求/方案/测试/总结全套文档
- 从 0 到 1 建立 LLM-as-a-Judge 量化评估闭环（相关性/准确性/幻觉率），以指标驱动产品迭代

**成果**：专业问答忠实度≥95%/相关率≥90%，本地化部署 Qwen3 内网稳定运行，交付链完整。
```

- 关键项目3：
    需要突出的要点有：`Agent 规约体系构想设计——面向 Agent 的工程化思考与设计能力；分支：企业服务/SaaS/云平台岗看工程治理与规约体系设计`  
    示范内容如下：
```markdown
#### Agent 规约体系构想设计 | 个人思考实践 | 2026.08 - 至今

**项目概述**：由"直接向 agent 下达任务不可靠、其产出依赖无歧义引导"这一观察出发，构想并设计面向多 Agent 协作的工程规约体系（提示词工程→harness 中间态）：人主导设计验收，规约约束 agent 交付。

**核心工作**：
- 三层架构+双载体：约束/知识/实例层，AGENTS.md 总入口与 .spec/ 索引
- 27 项机制：任务锚点三层追踪；Git 锚点↔commit hash 双向绑定+七项全局校验
- 校正"同账户只读=安全边界"等三处前提偏差，保留无脚本降级模式
- harness 化演进：五层分离，validate/check/anchor/render/hash 契约

**成果**：产出 4 份设计文档（体系设计/27 项机制清单/Git 追踪分析/harness 演进），已在个人仓库运行。
```

- 关键项目4：
    需要突出的要点有：`微服务 + 异步队列——SaaS 后端的解耦与吞吐设计；分支：与普通互联网组示范侧重一致，此处看企业级稳定性`  
    示范内容如下：
```markdown
#### 广州光点信息科技股份有限公司 | Python 开发实习生（AI 研发组） | 2025.03 - 2025.06

**项目概述**：全媒体热点追踪与 AI 自动化短视频生成矩阵系统，从 0 到 1 打通"监控-生成-合成"全链路。

**核心工作**：
- 基于 FastAPI 将大模型能力封装为独立微服务（要点提取/脚本二创标准接口）
- 引入 Celery + Redis 异步任务队列，解耦下载与推理流程，制定标准化 JSON 数据交换协议对接下游系统
- 本地 vLLM 部署 Qwen2.5-14B 与 Llama 3，复杂任务动态路由云端 API

**成果**：单条热点到视频产出从人工数小时压缩至 15 分钟内。
```
