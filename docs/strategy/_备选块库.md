- 备选块1：
    需要突出的要点有：`企业级定制软件工程化交付——业务 SOP 抽象为可配置判定逻辑 + 零代码交互 + 内网交付全链路`  
    示范内容如下：
```markdown
#### 南方电网广州电力工程监理有限公司 | 办公自动化 RPA 辅助软件开发项目 技术负责人 | 2024.10 - 2025.01

**项目概述**：面向电力监理业务的报表自动化 RPA 系统（已验收交付，￥10 万），将每日 1.5 小时手工统计压缩至 3 分钟。

**核心工作**：
- 业务 SOP 抽象与数据清洗：把定制的 Excel 筛选、分列与多条件统计抽象为高复用 Pandas 函数库，并打通 XLS/XLSX 底层 COM 转换与多源精准合并
- 架构升级决策（硬编码写表 → 数据-模板解耦）：统计结果先输出结构化 JSON，再由 config 坐标映射规则驱动注入目标 Excel，把报表结构从代码剥离为配置
- 零代码可视化交互引擎：数据勾选、督查反匹配与口径选择全部收敛到界面与配置文件，业务人员不接触代码即可自助完成全流程
- 工程化交付链路：全局日志捕获 + PyInstaller 打包与资源路径适配，保障甲方无 Python 环境的 Windows 内网终端稳定运行

**成果**：交付并应用于日常安全督查与计划管控业务，消除统计错漏。
```

- 备选块2：
    需要突出的要点有：`大型校企交付的全生命周期统筹 + 场景化分层架构 + 平台架构演进（Hub-Spoke / 二维数据分类 / 五态机）`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统迭代二期 项目总负责人 | 2025.07 - 2026.09

**项目概述**：合同 55 万的物流库区 AI 监控系统（校企联合框架累计 90 万），作为总负责人独立统筹立项到验收全生命周期。

**核心工作**：
- 独立主导全生命周期：业务调研 → 合作洽谈 → 技术合同拟定 → 立项 → 架构设计 → 验收交付
- 垂直场景建模：主导库区 11 类典型违规行为（车辆超速、人员离岗、晕倒摔倒等）的算法开发，基于 DeepSORT 运动轨迹分析 + MediaPipe / ST-GCN 时序行为分析
- 场景化分层架构：按业务场景设计「感知 → 时空建模 → 轨迹决策 → 响应中枢 → 系统赋能」五层，落地边缘轻量推理 + 中央归档检索协同
- 平台架构演进：平台侧由 Spring Boot 分层经业务 SOP 纵向分层，收敛为以通信中枢为中心的星形（Hub-Spoke）拓扑，配套二维数据分类治理与边缘设备五态机

**成果**：按期高质量验收交付，甲方续约信任度高。
```

- 备选块3：
    需要突出的要点有：`双节点边缘架构的权衡与取舍 + 可靠性治理闭环（协议冻结 / 状态机 / 自动降级）`  
    示范内容如下：
```markdown
#### 广东交科检测有限公司 | 钢筋直径与间距检测设备原型研发 技术负责人 | 2025.09 - 2026.09

**项目概述**：深度相机 + UNet 语义分割 + 4 路激光测距的钢筋直径与间距自动测量设备（POC 原型交付，￥25 万）。

**核心工作**：
- 双节点边缘架构决策与权衡：为消除推理与采集 / 渲染 / 串口在单板的争抢，把 AI 推理与系统调度隔离为两节点，以通信成本换取故障域隔离与推理节点可独立换型
- 节点间双向 gRPC + Protobuf 协议（独立 channel），配套状态机与帧同步机制（frame_id + 毫秒时间戳，乱序帧丢弃）
- AI 推理管线：UNet（ResNet50）3 类语义分割，等比缩放灰边填充入 640×640 → 标准化 → GPU 前向 → 裁边插值回原图 → argmax 输出掩码
- 多传感器融合与换算：4 路激光串口链路（帧解析、热插拔重连、融合切换），按 mm/px = 工作距离 ÷ 相机内参 fx 换算并对齐 6~40mm 国标

**成果**：端到端原型已交付，自动输出直径与间距并实时显示。
```

```markdown
#### 南网数字研究院/江门供电局 | 边缘布控球自适应目标检测与视频调控系统 大创技术总负责人 | 2024.06 - 2024.10

**项目概述**：电网施工布控球在弱网、边缘算力受限（海思 Hi3519DV500 NPU，无 GPU/CUDA）下的端云协同视频监控系统，后立项为省级大创项目。

**核心工作**：
- 端云协同架构与方案统筹：主笔《图像质量评估及优化方案》，针对海思算力瓶颈设计「边缘端 Brenner / 亮度指标初筛 + HSV 明度自适应」与「服务端 Transformer NR-IQA 评估」的折中架构
- 云台自适应跟踪算法验证：独立编写 YOLOv8 + ByteTrack 视频跟踪测试脚本，设计基于线性插值（Lerp）与帧间平滑的云台控制逻辑，输出 x/y 偏移与焦距缩放信号
- 评估体系与数据集：协助构建电网多曝光图像融合数据集（WireFO-MEF），制定亮度与清晰度主观打分规范，编写自动化脚本验证评估体系

**成果**：获批省级大创立项；边缘端客观评分召回率 / 精准率 70%+，主客观一致率 80%+。
```
