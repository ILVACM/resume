## 适用领域分组

政企信科

## 方案构建意图简述

① 本组为 to G（客户／用人单位＝政府、事业单位、国企），最看重数据不出域、本地化部署与需求期望管理。
② 本方案以测绘院、办公自动化RPA、机场物流、布控球四条为骨架：测绘院与机场物流证明本地化合规交付与大型项目统筹，RPA证明已验收的定制软件交付，布控球证明南网纵向课题持续合作。
③ 与同届相比，形成「本地化合规交付+定制软件验收记录+大型项目统筹」的组合，且每一环都有可追问的量化机制。

## 关键优势项目

- 关键项目1：
    需要突出的要点有：`本地化部署 + 数据不出域 + 需求期望管理——政企交付三要素齐备，且交付链（需求/技术方案/测试/工作总结）完整；分支：政企软件公司看合规与交付流程，集成商看驻场协同`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10
**项目概述**：GDCORS 智能知识库与政企本地化 RAG 问答系统，在数据"绝对不出域"的严苛合规要求下交付。

**核心工作**：
- 采用「逻辑核心 + 功能插件」微内核架构与六层分层设计，使检索链路各环节可独立替换而不触动核心
- 以本地 BERT 微调模型作用户意图二分类路由，实现数据隔离分流（内部分支不出内网、外部受控访问）与三级权限治理
- 深入业务一线多轮需求调研，通过早期 Demo 与量化评估数据管理甲方期望，将项目目标从"开放式通用问答"收敛至"精准检索与故障排查"，规避范围蔓延
- 协调信息中心争取本地算力资源，完成核心数据盘点与授权
- 基于 vLLM 本地量化部署 Qwen3，Docker + Nginx 容器化与反向代理，内网弱网环境稳定运行

**成果**：忠实度≥95%/相关率≥90%，需求/技术方案/测试/工作总结交付链完整。
```

- 关键项目2：
    需要突出的要点有：`央企（南方电网）场景的定制软件交付——已验收的央企合作记录；分支：央企/国企信息化供应商看甲方内网交付能力`  
    示范内容如下：
```markdown
#### 南方电网广州电力工程监理有限公司 | 办公自动化 RPA 辅助软件开发项目 技术负责人 | 2024.10 - 2025.01
**项目概述**：面向电力监理业务的数据清洗与报表自动化 RPA 系统（已验收交付），将每日 1.5 小时手工统计压缩至 3 分钟。

**核心工作**：
- 架构升级决策：摒弃硬编码写表，将统计结果先输出结构化 JSON，再由坐标映射规则驱动注入目标 Excel，报表模板变更只需改配置无需改代码
- 零代码可视化交互引擎：将数据表勾选、统计口径选择收敛至可视化界面与配置文件，甲方业务人员不接触代码即可自助完成全流程，新增报表或调整口径均由配置完成
- GUI 可视化封装 + PyInstaller 打包，确保甲方无 Python 环境的 Windows 内网终端稳定运行

**成果**：系统成功交付并应用于日常安全督查业务，获甲方业务部门高度评价。
```

- 关键项目3：
    需要突出的要点有：`国企客户（机场物流集团）大型项目交付——累计 90 万校企框架的履约记录；分支：大型政企项目投标看履约与统筹能力`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统迭代二期 项目总负责人 | 2025.07 - 2026.09
**项目概述**：合同 55 万的库区 AI 监控系统（校企联合框架累计 90 万），本人作为总负责人独立统筹全生命周期。

**核心工作**：
- 从业务调研、合作洽谈、技术合同拟定到立项、架构设计、验收交付均作为核心决策者推进
- 主导多场景 AI 视觉算法攻坚与国产边缘算力部署
- 多端协同与场景化分层架构：针对库区违规场景设计分层技术架构（感知→时空建模→轨迹决策→响应中枢→系统赋能），落地边缘端轻量化推理 + 中央服务器归档检索的多端协同形态
- 系统平台架构设计与演进：由 Spring Boot 分层起步、按业务 SOP 重组为纵向分层、最终收敛为通信中枢为中心的星形 Hub-Spoke 拓扑；配套二维数据分类治理与边缘设备五态机全生命周期管理

**成果**：按期高质量验收，获甲方高层认可并续建二期。
```

- 关键项目4：
    需要突出的要点有：`南网纵向课题经历——政企客户（南方电网）的持续合作背书；分支：政企软件公司看南方电网场景与产学研合作资历，集成商看纵向课题的合规交付经验`  
    示范内容如下：
```markdown
#### 南网数字研究院/江门供电局 | 边缘布控球自适应目标检测与视频调控系统 大创技术总负责人 | 2024.06 - 2024.10
**项目概述**：电网施工布控球在弱网、边缘算力受限环境下的端云协同视频监控系统（省级大创立项）。

**核心工作**：
- 主导端云协同系统架构设计，主笔《图像质量评估及优化方案》，设计边缘初筛 + 服务端深度评估的折中架构，平衡边缘算力与评估精度
- 独立编写 YOLOv8 + ByteTrack 跟踪测试脚本，基于 Lerp 线性插值与帧间平滑实现云台自适应跟踪控制逻辑
- 构建电网场景多曝光图像融合数据集（WireFO-MEF），制定亮度与清晰度主观打分标注规范，编写自动化测试脚本验证评估体系
- 确保边缘端客观评分召回率/精准率 70%+、服务端主客观一致评分 80%+，为后续核心算法迭代提供量化支撑

**成果**：边缘客观评分召回率/精准率 70%+，获批省级大创立项。
```
