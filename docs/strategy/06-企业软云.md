## 方案构建意图简述

① 本组为 to B 信息服务（客户＝各类企业），最看重工程化交付与可维护可配置；专做 to G 者见「政企信科」。
② 本方案选「机场物流二期（撑企业级平台架构与云边交付）+ 电力监理 RPA（撑可配置化交付与架构升级决策）+ 测绘院知识库（撑产品化与权限治理）」三条为骨架。
③ 与同届相比，形成"能交付可配置企业软件 + 有企业级平台架构设计能力 + 有工程规约体系"的组合，而非只做过脚本工具（规约体系完整块见 01 组）。

## 关键优势项目

- 关键项目1：
    需要突出的要点有：`企业级平台架构契约化（Hub-Spoke 通信中枢）+ 存储与数据分层治理 + Docker 容器化云边监控——企业级系统平台架构与「云」方向的直接证据；分支：云/平台/基础架构岗看组件解耦与契约化设计，乙方平台交付公司看大型项目架构统筹`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统迭代二期 项目总负责人 | 2025.07 - 2026.09

**项目概述**：合同 55 万的库区 AI 监控系统（校企联合框架累计 90 万），作为总负责人独立统筹立项到验收全生命周期。

**核心工作**：
- 服务端平台架构演进（决策链）：由 Spring Boot 分层 → 纵向业务分层 → 以通信中枢为中心的星形（Hub-Spoke）拓扑，把「组件两两耦合」收敛为「组件对中枢的单一契约」，新增组件或替换协议均不影响既有链路
- 多端协同与场景化分层：按场景设计「感知→时空建模→轨迹决策→响应中枢→系统赋能」五层，落地边缘轻量推理 + 中央归档检索协同
- 数据与存储治理：以二维数据分类明确各类数据的通道与存储归属，规划归档与检索分工；配套 MySQL 定时备份
- Docker 容器化部署与云边监控体系（Prometheus + Grafana，15+ 告警），可用性 99.5%、P1 恢复 <5 分钟

**成果**：按期高质量验收，获甲方高层认可。
```

- 关键项目2：
    需要突出的要点有：`架构升级决策（数据-模板解耦）+ JSON 配置化引擎 + GUI 交付 + 企业内网部署——企业软件工程化交付全链路；分支：SaaS/企业软件公司看可维护性设计（配置化与架构决策），乙方交付公司看甲方内网落地能力`  
    示范内容如下：
```markdown
#### 南方电网广州电力工程监理有限公司 | 办公自动化 RPA 辅助软件开发项目 技术负责人 | 2024.10 - 2025.01

**项目概述**：面向电力监理业务的数据清洗与报表自动化 RPA 系统（已验收交付），将每日 1.5 小时手工统计压缩至 3 分钟。

**核心工作**：
- 架构升级决策（决策 → 方案 → 收益）：摒弃硬编码写表，改为「结构化 JSON 输出 + config 坐标映射驱动注入」两段式；把报表结构从代码剥离为配置，以一次改造换取模板变更零代码改动
- 面向非技术用户的零代码可视化交互引擎：数据勾选/督查反匹配/口径选择全收敛到 GUI 与配置文件，业务人员不接触代码即可自助完成数据导入到报表输出全流程
- 攻克异构数据源融合：XLS/XLSX 底层 COM 转换、空白行列剔除、多源 Merge 精准合并
- PyInstaller 打包 + 全局日志捕获的交付链路，确保甲方无 Python 环境的 Windows 内网终端稳定运行

**成果**：系统成功交付并应用于日常安全督查业务，消除人工统计错漏，获甲方高度评价。
```

- 关键项目3：
    需要突出的要点有：`微内核六层架构（检索链路可独立替换）+ 企业知识库产品化 + 量化评估闭环——企业服务公司看知识管理/检索产品的落地方法论；分支：与 agent 组示范侧重不同，此处强调架构设计、产品化与交付`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10

**项目概述**：GDCORS 智能知识库——面向测绘院海量非结构化专业文档与 PB 级业务数据的本地化知识管理产品，满足政企数据"不出域"合规要求。

**核心工作**：
- 主导需求调研与期望管理：以 Demo 与量化数据收敛目标，把范围从通用问答收敛至"精准检索与故障排查"
- 系统架构设计：采用「逻辑核心 + 功能插件」微内核 + 六层分层，插件标准接口挂载向量库 / 模型 / 意图识别，检索链路各环节可独立替换
- 数据隔离分流与权限治理：BERT 微调意图二分类路由（内部本地库、外部受控通道），三级权限
- 打通文档解析到向量检索链路：千万级文档块入库 Milvus，交付需求/方案/测试/总结全套文档
- 从 0 到 1 建立 LLM-as-a-Judge 量化评估闭环（相关性 / 准确性 / 幻觉率）

**成果**：专业问答忠实度≥95%/相关率≥90%，本地化部署 Qwen3 内网稳定运行，交付链完整。
```
