## 适用领域分组

金融证券 / 金融科技

## 方案构建意图简述

① 金融类岗位最看重数据合规与履约稳定——能否在强监管下把系统安全交付并长期履约。
② 本方案以机场物流、测绘院、办公自动化RPA三条为骨架：机场物流证明大型项目交付与云边监控体系，RPA证明已验收的报表自动化流程，测绘院证明数据不出域的合规架构——与金融数据安全同源。
③ 与同届相比，形成「合规架构+履约记录+流程自动化」的组合，且每一环都对应金融岗位的真实需求。

## 关键优势项目

- 关键项目1：
    需要突出的要点有：`大型国企客户（机场物流集团）累计 90 万项目交付记录——金融机构看履约稳定性与责任担当；分支：银行/券商科技岗看交付统筹，数据岗看监控体系`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统迭代二期 项目总负责人 | 2025.07 - 2026.09
**项目概述**：合同 55 万的库区 AI 监控系统（校企联合框架累计 90 万），本人作为总负责人独立统筹从立项到验收的全生命周期。

**核心工作**：
- 独立推进业务调研、技术合同拟定、立项、架构设计与验收交付，全流程按合同履约交付
- 多端协同分层架构：针对库区违规场景设计感知→时空建模→轨迹决策→响应中枢→系统赋能五层，落地边缘端轻量化推理 + 中央服务器归档检索协同形态
- 系统平台架构演进：由 Spring Boot 分层起步、经纵向业务分层、收敛为星形 Hub-Spoke 拓扑；配套二维数据分类治理与五态机管理
- 建立 Docker 容器化部署与云边监控体系（Prometheus + Grafana，15+ 告警规则），系统可用性 99.5%、P1 故障恢复 <5 分钟
- 以一期验收效果促成甲方委托续建二期，形成同一客户的长期合作记录

**成果**：两期均按期高质量验收，甲方续约信任度高。
```

- 关键项目2：
    需要突出的要点有：`数据"不出域"合规架构——与金融数据安全合规要求同源；分支：金融机构数据安全/合规科技岗直接对口本地化部署经验`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10
**项目概述**：GDCORS 智能知识库与政企本地化 RAG 问答系统，在数据"绝对不出域"的严苛合规要求下交付。

**核心工作**：
- 采用「逻辑核心 + 功能插件」微内核架构与六层分层设计，使检索链路各环节可独立替换而不触动核心
- 以本地 BERT 微调模型作用户意图二分类路由，实现数据隔离分流（内部分支不出内网、外部受控访问）与三级权限治理
- 基于 vLLM 本地量化部署 Qwen3，Docker + Nginx 容器化与反向代理，内网弱网环境稳定运行
- 从 0 到 1 构建 LLM-as-a-Judge 量化评估体系（相关性/准确性/幻觉率），忠实度≥95%/相关率≥90%
- 协调完成核心数据盘点与授权

**成果**：本地化系统稳定交付运行，满足严苛合规要求。
```

- 关键项目3：
    需要突出的要点有：`流程自动化 RPA（已验收交付）——银行/金融机构流程自动化需求的直接对口；分支：金融科技子公司看 RPA 与报表自动化经验`  
    示范内容如下：
```markdown
#### 南方电网广州电力工程监理有限公司 | 办公自动化 RPA 项目 技术负责人 | 2024.10 - 2025.01
**项目概述**：面向电力监理业务的数据清洗与报表自动化 RPA 系统（已验收交付），把日报、周报等重复性报表流程转化为一键式自动化流水线。

**核心工作**：
- 架构升级决策：摒弃硬编码写表，将统计结果先输出结构化 JSON，再由坐标映射规则驱动注入目标 Excel，报表模板变更只需改配置、无需改代码
- 零代码可视化交互引擎：将数据表勾选、统计口径选择收敛至可视化界面与配置文件，甲方业务人员不接触代码即可自助完成全流程，新增报表或调整口径均由配置完成
- 将"次日基建计划统计、C/D 类违章代码核查、周计划出勤核算"等重复业务流程，抽象为高复用 Pandas 处理函数库
- GUI 可视化封装 + PyInstaller 打包，适配甲方无 Python 环境的 Windows 内网终端

**成果**：每日 1.5 小时手工统计压缩至 3 分钟内，消除人工统计错漏。
```
