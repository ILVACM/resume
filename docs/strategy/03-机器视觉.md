## 关键优势项目

- 关键项目1：
    需要突出的要点有：`11 类违规行为检测 + 多目标跟踪 + 时序行为识别，且为项目总负责人——CV 算法岗看算法栈（DeepSORT/ST-GCN），工程岗看全生命周期统筹；分支：算法岗侧重 bullets 前两条，项目管理岗侧重末条`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统迭代二期 项目总负责人 | 2025.07 - 2026.09

**项目概述**：合同 55 万的转运库区违规行为 AI 监控系统，覆盖车辆超速、人员离岗、晕倒摔倒等 11 类典型违规行为。

**核心工作**：
- 基于 DeepSORT 构建运动轨迹分析模块，结合 MediaPipe 与 ST-GCN 时空图卷积网络进行时序行为分析，初期检出准确率 60%-70%（目标 80%+）
- 主导安检机专有协议壁垒攻坚，实现高并发视频流稳定推送、提取与硬解码
- 项目总负责人：独立主导立项、架构设计到验收交付全生命周期

**成果**：按期高质量验收交付，甲方委托横向拓展二期（合同 55 万）。
```

- 关键项目2：
    需要突出的要点有：`UNet 语义分割（3 类掩码）+ 像素到物理尺寸换算——分割管线细节与测量应用结合；分支：工业检测/测量仪器类公司直接对口`  
    示范内容如下：
```markdown
#### 广东交科检测有限公司 | 钢筋直径与间距检测设备原型研发 技术负责人 | 2025.09 - 2026.09

**项目概述**：深度相机采集 + UNet（ResNet50 backbone）3 类语义分割（背景/纵筋/横筋）+ 4 路激光测距的钢筋直径与间距自动测量设备。

**核心工作**：
- 构建 UNet 推理管线：等比缩放+灰边填充 640×640 → ImageNet 标准化 → GPU 前向 → 裁边插值回原图 → 逐像素 argmax
- 基于"mm/px = 工作距离 ÷ 相机内参 fx"完成像素到物理尺寸换算，输出直径就近对齐 6~40mm 国标规格
- 设计帧同步机制（frame_id 主键+时间戳校验），杜绝 RGB/距离/掩码跨帧错配

**成果**：端到端原型已交付（POC 技术验证完成），自动输出直径与相邻间距并实时叠加显示。
```

- 关键项目3：
    需要突出的要点有：`YOLOv8+ByteTrack 跟踪与图像质量评估（IQA）体系——检测跟踪与质量评估复合能力；分支：监控/视频分析类公司看弱网边缘场景落地`  
    示范内容如下：
```markdown
#### 南网数字研究院/江门供电局 | 边缘布控球系统 大创技术总负责人 | 2024.06 - 2024.10

**项目概述**：电网施工布控球在弱网、边缘算力受限（海思 Hi3519DV500 NPU，无 GPU/CUDA）环境下的端云协同视频监控系统。

**核心工作**：
- 独立编写 YOLOv8 + ByteTrack 视频跟踪测试脚本，完成目标检测与多目标跟踪链路的边缘侧验证
- 主笔《图像质量评估及优化方案》：构建"边缘端 Brenner/亮度客观指标初筛 + 服务端 Transformer NR-IQA 拟人化评估"的图像质量评估体系
- 构建电网多曝光图像融合数据集（WireFO-MEF），边缘端客观评分召回/精准率 70%+，主客观一致率 80%+

**成果**：获批省级大创立项，为布控球视频分析链路提供算法验证基线。
```
