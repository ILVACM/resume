## 适用领域分组

领域专用软件开发

## 方案构建意图简述

① 领域专用软件方向最看重"能否做出真正落地到垂直行业的专用软件，打通需求到交付的闭环"。
② 本方案选「交科检测设备（技术负责人，撑专用设备软件全链路与 Agent 规约前置）+ 测绘院知识库（撑知识工程与权限治理）+ 电力监理 RPA（撑业务 SOP 软件化）+ 嵌入式竞赛（撑软硬件结合基础）」四条为骨架。
③ 与同届相比，形成"能啃垂直领域硬骨头 + 有架构权衡与工程治理 + 软硬结合"的组合，而非只做过通用网页应用。

## 关键优势项目

- 关键项目1：
    需要突出的要点有：`专用检测设备软件全链路（需求→算法→硬件→实测）——"领域专用"的完整叙事；分支：工业软件/检测仪器公司看垂直场景闭环能力`  
    示范内容如下：
```markdown
#### 广东交科检测有限公司 | 钢筋直径与间距检测设备原型研发 技术负责人 | 2025.09 - 2026.09
**项目概述**：针对施工现场钢筋检测依赖人工卡尺抽检的痛点，研制基于边缘计算的专用测量设备：深度相机 + UNet 语义分割 + 4 路激光测距，双节点架构本地闭环。

**核心工作**：
- 架构决策与权衡：推理与调度负载物理隔离为双节点，以通信成本换取故障域隔离与可独立换型
- 项目级 Agent 规约体系与架构规范前置：仓库根 AGENTS.md 作约束层，冻结模块/通信协议/开发规范，形成「约束层→实例层」两级
- 设计双节点边缘架构与双向 gRPC 通信协议（自定义 protobuf），实现像素换算与直径/间距输出
- 工程治理三件套：协议冻结—状态机—自动降级闭环，全量参数 JSON 配置化与双节点统一日志规范，现场可自证状态、可安全退化

**成果**：端到端原型已交付（POC 技术验证完成），具备转入正式开发阶段的代码资产基础。
```

- 关键项目2：
    需要突出的要点有：`测绘/GIS 领域专用知识库——垂直领域知识工程经验；分支：南方数码等测绘/GIS 公司直接对口，其他领域公司看知识工程方法论迁移`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10
**项目概述**：GDCORS 智能知识库，面向测绘院内部海量非结构化专业文档（GDCORS 操作手册、测绘规范、扫描版图纸）与 PB 级地理空间业务数据。

**核心工作**：
- 采用「逻辑核心 + 功能插件」微内核架构与六层分层设计，使检索链路各环节可独立替换而不触动核心
- 以本地 BERT 微调模型作用户意图二分类路由，实现数据隔离分流（内部分支不出内网、外部受控访问）与三级权限治理
- 主导分布式文档解析流水线，攻克扫描版图纸与复杂表格解析难题（OCR+版面分析）
- 引入 HyDE、多路召回（向量+BM25）与 BGE-Reranker 重排序，适配测绘领域长尾复杂查询
- 从 0 到 1 构建 LLM-as-a-Judge 量化评估体系，专业问答准确率 90%+

**成果**：本地化 RAG 系统交付运行，辅助技术人员快速定位故障与查询规范。
```

- 关键项目3：
    需要突出的要点有：`电力监理领域专用 RPA 工具——垂直业务 SOP 的软件化样板；分支：垂直领域软件公司看业务抽象与配置化设计`  
    示范内容如下：
```markdown
#### 南方电网广州电力工程监理有限公司 | 办公自动化 RPA 项目 技术负责人 | 2024.10 - 2025.01
**项目概述**：将电力监理"次日基建计划统计、C/D 类违章代码核查、周计划出勤核算"等重复业务流转化为一键式自动化流水线（已验收交付）。

**核心工作**：
- 架构升级决策：摒弃硬编码写表，将统计结果先输出结构化 JSON，再由坐标映射规则驱动注入目标 Excel，报表模板变更只需改配置无需改代码
- 零代码可视化交互引擎：将数据表勾选、统计口径选择收敛至可视化界面与配置文件，甲方业务人员不接触代码即可自助完成全流程，新增报表或调整口径均由配置完成
- 深入调研甲方业务 SOP，将定制化 Excel 需求抽象为高复用 Pandas 处理函数库
- GUI 封装降低非技术人员使用门槛，PyInstaller 打包适配甲方内网终端

**成果**：每日 1.5 小时手工统计压缩至 3 分钟，消除人工错漏。
```

- **华为2024鲲鹏应用创新大赛**：全国半决赛（开发板赛道）
