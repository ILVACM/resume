## 适用领域分组

物联网

## 方案构建意图简述

① 该领域最看重能否把硬件、通信、软件打通成一套可运行的物联系统。
② 本方案以「交科双节点架构 + 机场硬件到云边监控全栈 + 布控球国产边缘盒子部署 + 工程项目架构设计方法探索」四条为骨架：前三条证设备全链路、硬件落地到运维、国产边缘适配；末条证不止会写代码，对项目规划设计与工程架构有专门的方法论探索。

③ 相比同届，形成懂设备全链路 + 会国产边缘适配 + 有架构方法论沉淀的组合。

## 关键优势项目
- 关键项目1：
    需要突出的要点有：`双节点边缘架构 + 串口/协议 + 多传感器融合——设备研发经验最完整（架构/通信/传感器/可靠性全链路）；分支：智能硬件公司看设备研发全链路，模组/芯片公司看通信与传感细节`  
    示范内容如下：
```markdown
#### 广东交科检测有限公司 | 钢筋直径与间距检测设备原型研发 技术负责人 | 2025.09 - 2026.09
**相关技术栈**：Python / Jetson Nano / OrangePi / gRPC / protobuf / UNet(ResNet50) / PySerial / OpenCV

**项目背景**：建筑施工现场钢筋直径与间距检测依赖人工卡尺抽检，效率低、覆盖率不足，且难以满足大规模施工的质检追溯需求。
**项目定位**：广东交科检测有限公司横向课题（合同 XX 万），本人任技术负责人，主导双节点边缘架构设计、算法部署与原型交付。

**核心工作**：
- 针对施工场景无 GPU 算力且需多传感器协同的瓶颈，设计 Jetson Nano（推理） + OrangePi（采集/换算）双节点边缘架构，以通信成本换故障域隔离，实现推理节点离线时自动降级至「仅视频+激光」基础模式
- 针对节点间状态同步与通信可靠性需求，设计 gRPC + protobuf 双向协议（独立 channel），配套帧同步算法与状态机（IDLE→INFERENCING→RETURNING），实现节点健康自诊断与异常自动恢复
- 针对 4 路激光测距传感器数据融合难题，打通串口通信全链路（帧解析 / 热插拔自动重连 / 融合策略动态切换），完成像素至物理尺寸映射换算，使直径测量值自动匹配 6~40mm 国标规格

**成果**：端到端原型已交付（POC 技术验证完成），实现直径与间距的自动测量与实时叠加显示。
```
- 关键项目2：
    需要突出的要点有：`IoT 硬件底座 + 现场部署运维 + 云边协同监控 + 系统架构演进——从硬件组装到服务器集群的物联系统全栈；分支：家电/制造类公司看硬件落地与运维体系`  
    示范内容如下：
```markdown
#### 机场物流集团 | 智慧物流系统迭代一/二期 | 项目总负责人（二期） | 2024.09 - 2026.09
**相关技术栈**：Spring Boot / Docker / MySQL / Redis / Prometheus / Grafana / IoT 架构

**项目背景**：机场转运库区依赖人工巡逻与事后录像回溯，违规行为发现滞后、取证难，无法满足多库区规模化实时监管需求。
**项目定位**：校企联合框架二期（合同 55 万 / 累计框架 90 万），本人任二期总负责人独立统筹全生命周期。

**核心工作**：
- 针对库区多场景违规识别需求，主导设计「边缘轻量推理 + 中央归档检索」多端协同分层架构，完成安检机硬件组装与电气负载校验（一期），落地 11 类违规 AI 视觉算法（二期）
- 针对组件间两两耦合导致扩展困难的问题，主导平台架构由 Spring Boot 分层 → 纵向分层 → 星形 Hub-Spoke 拓扑演进，配套二维数据分类治理与边缘设备五态机全生命周期管理
- 针对项目无运维保障体系的现状，搭建 Docker 容器化 B/S 部署与 Prometheus+Grafana 云边监控体系（15+ 告警），使 P1 故障恢复时间控制在 5 分钟以内、系统可用性达到 99.5%

**成果**：两期均按期通过验收并完成交付，为后续 AI 视觉技术在物流场景中的拓展应用奠定基础。
```
- 关键项目3：
    需要突出的要点有：`海思 NPU 边缘盒子部署——国产边缘平台适配经验；分支：边缘盒子/安防硬件厂商直接对口`  
    示范内容如下：
```markdown
#### 南网数字研究院/江门供电局 | 边缘布控球自适应目标检测与视频调控系统 技术总负责人 | 2024.06 - 2024.10
**相关技术栈**：Python / YOLOv8 / ByteTrack / 海思 NPU / PyTorch / 图像质量评估（Brenner / NR-IQA）

**项目背景**：电网施工布控球部署于弱网、边缘算力受限（海思 Hi3519DV500 NPU，无 GPU/CUDA）的作业现场，视频质量与目标跟踪效果难以保障。
**项目定位**：南方电网数字研究院纵向课题（后续立项为省级大创），任技术总负责人。

**核心工作**：
- 针对海思 NPU 边缘算力受限无法运行复杂评估模型的瓶颈，主笔《图像质量评估及优化方案》设计端云协同架构：边缘端以 Brenner/亮度指标初筛过滤明显异常，服务端以 Transformer NR-IQA 做精细化评估，平衡算力占用与评估精度
- 针对布控球在动态场景下目标易丢失的问题，独立编写 YOLOv8 + ByteTrack 视频跟踪测试脚本，设计基于 Lerp 线性插值与帧间平滑的云台自适应控制逻辑，输出实时 x/y 偏移与焦距缩放信号
- 针对电网场景缺乏客观图像融合评估基线的问题，构建 WireFO-MEF 多曝光数据集并制定清晰度主观打分规范，通过自动化测试脚本验证：边缘端客观评分召回/精准率达 70%+、服务端主客观一致率达 80%+

**成果**：相关成果获批省级大创立项，为国产边缘平台上的图像质量评估算法提供验证基线。
```
