## 关键优势项目

- 关键项目1：
    需要突出的要点有：`多模态大模型 + RAG + Multi-Agent 直接对口大模型算法与应用岗——科研经历体现研究深度（文献调研/基金申请书撰写），分支：算法研究岗看科研深度，应用岗看 RAG 架构验证与数据流水线工程化`  
    示范内容如下：
```markdown
#### 广东省自然科学基金2026（面上） | 核心算法开发成员 | 2025.06 - 至今

**项目概述**：《模态缺失下的轻量化诊疗报告生成研究》（编号 2026A1515010964），依托中山大学肿瘤防治中心 600+ 例多模态私有数据集，研究"补全-验证-轻量化"技术链。

**核心工作**：
- 参与 Multi-Agent 系统工程架构设计与验证，实现智能体串行/并行调度逻辑
- 接入 RAG 外挂临床指南知识库，验证"诊断-验证-仲裁"闭环机制抑制医学幻觉的工程可行性
- 独立负责 GPU 服务器环境（Docker/Conda）与 600+ 例数据集清洗、脱敏、ROI 裁剪的标准化流水线

**成果**：完成多模态特征编码与多时序轻量化模型基础代码搭建；协助完成基金申请书核心内容撰写。
```

- 关键项目2：
    需要突出的要点有：`RAG 全链路工程化落地（意图路由/多路召回/Reranker/量化评估）且本地化部署——RAG 应用岗与知识库产品岗直接对口；分支：政企背景公司同时体现"数据不出域"合规能力`  
    示范内容如下：
```markdown
#### 广东省国土资源测绘院 | 系统开发实习生（卫星应用中心） | 2025.07 - 2025.10

**项目概述**：GDCORS 智能知识库与政企本地化 RAG 问答系统，面向 PB 级地理空间业务数据与海量专业文档，满足政企数据"不出域"合规要求。

**核心工作**：
- 主导分布式文档解析流水线（OCR+版面分析），千万级文档块存入 Milvus 向量库
- 设计意图识别路由 + HyDE + 多路召回（向量+BM25）+ BGE-Reranker 重排序
- 从 0 到 1 构建 LLM-as-a-Judge 量化评估体系（相关性/准确性/幻觉率），反哺迭代

**成果**：专业问答准确率提升至 90% 以上；基于 vLLM 本地化部署 Qwen2.5-14B，内网稳定运行。
```

- 关键项目3：
    需要突出的要点有：`LLM 微服务化 + 混合推理调度（本地 vLLM + 云端 API）+ 异步编排——AI 工程化应用岗直接对口；分支：AI 应用开发岗看微服务解耦与调度策略设计`  
    示范内容如下：
```markdown
#### 广州光点信息科技 | Python 开发实习生（AI 研发组） | 2025.03 - 2025.06

**项目概述**：全媒体热点追踪与 AI 自动化短视频生成矩阵系统，从 0 到 1 打通"监控-生成-合成"全链路。

**核心工作**：
- 基于 FastAPI 将大模型能力封装为独立微服务（要点提取/脚本二创标准接口）
- 本地 vLLM 部署 Qwen2.5-14B 与 Llama 3 处理常规任务，复杂创意动态路由云端 API，设计 API Key 池轮询与指数退避重试
- 本地部署 faster-whisper 与 SenseVoice 双 STT 引擎，按音频时长与场景智能路由
- 引入 Celery + Redis 异步任务队列，解耦下载与推理流程

**成果**：单条热点到视频产出从人工数小时压缩至 15 分钟内。
```
